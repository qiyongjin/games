# 弈步 · 中国象棋教学小游戏

在浏览器里和电脑下象棋，在每一步中理解规则。默认执红先走、开启教学，提供入门和普通两档人机。

## 启动

需要 Node.js 20 或更新版本，无需安装依赖。在本目录运行：

```powershell
npm run dev
```

然后打开 http://127.0.0.1:5173 。按 `Ctrl+C` 停止服务。端口被占用时可在 PowerShell 中先运行 `$env:PORT=5174` 再启动。

请通过本地 HTTP 服务打开页面；直接双击 HTML 文件时，浏览器不能正常加载模块与 Worker。

## 怎么玩

- 点击一枚红棋，查看它的走法和合法落点；再次点击落点移动。圆点表示可移动，圆环表示可吃子。
- 教学开启时，先阅读红方落子的讲解，再点击“让电脑走”；电脑走完后，继续红方回合。关闭教学后电脑自动应手。
- “给我一点提示”只画出建议与讲解，不自动走棋。
- 电脑未落子时悔棋撤回红方一步；电脑已落子时撤回双方两步。对局结束后也可悔棋。
- 教学设置、难度和对局自动保存在当前浏览器的本地存储中，刷新可继续。清除浏览器数据会清除进度。
- 键盘操作：Tab 进入棋盘，方向键移动焦点，回车选子/落子，Esc 取消选择。

## 规则范围

包含七种棋子走法、马腿、象眼、炮架、河界与九宫、将帅照面、应将、将死与困毙。将帅不作为普通棋子被吃掉，正常对局以无法合法应对结束。

重复局面使用**教学休闲规则**：同一棋子分布及轮走方第四次出现时，检查该重复区间；若只有一方在其每一步都将军，该方判负，其余情况判“教学和棋”。暂不裁定复杂长捉，不能代替完整赛事棋例。

基础行棋依据：[世界象棋联合会《世界象棋规则》](https://www.wxf-xiangqi.org/images/wxf-rules/2018_World_Xiangqi_Rules_Chinese_2018.pdf)。

## 验证

```powershell
npm test
```

测试覆盖规则边界、终局与重复、教学事实、存档恢复和悔棋，以及人机搜索的合法性与取消逻辑。

## 结构与后续扩展

- `src/engine.js`：不可变局面、走法校验、合法走法和终局。
- `src/coach.js`、`src/session.js`：教学讲解、对局历史、悔棋及本地存档。
- `src/search.js`、`src/ai-worker.js`：限时迭代加深搜索，在 Worker 中执行。
- `src/opponent.js`：异步对手接口 `requestMove(position, { difficulty, signal, entries })`，传入对局历史以遵守重复规则。后续真人对弈可接入新适配器，复用规则与棋盘。
- `src/app.js`：界面、交互与异步结果校验。

首版为纯静态本地应用，对弈无需外部服务或付费 AI。以后可将静态文件部署到网站托管平台，再按需要增加真人房间与服务端裁决。
